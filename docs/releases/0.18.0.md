**A new icon, an app that looks and behaves like a Mac app, and everything you can do on a GitHub PR now reachable in LGTM.**

**Do it here, as on GitHub**
- **Merge any PR you may merge**: a bot's from the bar, anyone else's from ⋯ (m); Merge all in Your PRs → Ready to merge, after one confirmation.
- **By your rights, not authorship**: ask, re-request and replace reviewers; assign people; edit a merged PR; Update with rebase; re-run any job, re-run all, cancel a run, approve a first-time contributor's workflows and deployments waiting on you.
- **Details in the index**: labels, milestone, GitHub Projects, linked Jira tickets and issues in one section, each added from its header and taken off with a chip's ×.
- **People in the index**: who opened it, assignees and reviewers in one list, a line saying who it waits on, Slack's mark by anyone you've talked to about it.
- **GitHub and GitLab issues** a PR closes as cards, like Jira tickets; a new issue or ticket from any comment (h).
- **Deployments as pills** under the title: open a preview, watch one deploy, read a failed one's log.
- **Edited comments marked "edited"**: a click lists each version and shows what that edit changed.
- **Who reacted** on hovering an emoji reaction.
- **Edit the title and description** with e.

**Reviewing**
- **Comment on several lines** by dragging the line numbers, in one column, side by side and rendered Markdown; select code and Comment quotes it.
- **Side by side per file**, from each file's header.
- **Changes from one commit or a run of them**, picked at the top of the index's Files.
- **Rendered Markdown's changed lines barred** by default, styled apart from code's (Settings → Diff), with one live preview for every Diff setting.
- **The index on the left or right** (Settings → Diff); scrolling it no longer moves the page.
- **Back and forward in review mode.**

**Your PRs**
- **PRs assigned to you are yours**: a bot's to review and merge, a person's to merge once others review (Settings → PR list).
- **Most urgent first** in each group: the highest Jira or issue priority, people before bots, then age.
- **Coding agents fix it for you**: a conflict, a To fix PR, or your review sent straight to the PR's Claude Code session or Codex conversation, a new one when it has none.

**A Mac app**
- **A new icon**, a diff stamped LGTM in GitHub's purple, in light, dark and tinted on macOS 26; LGTM in capitals.
- **The menu bar** with Go and Review menus holding every action (its key beside it) and an SF Symbol on each item; a native menu bar menu.
- **Native window manners**: traffic lights centred, the whole bar drags, no WebKit menu on a right-click, the window titled by what's open.
- **macOS's accent colour**, Reduce transparency and Differentiate without colour followed.
- **One Inbox** with the bell's updates above the replies waiting on you; right-click its button for a quick look.
- **A Display menu** for the theme, side by side, reading width, whitespace and the shortcuts.

**Look**
- **Buttons that look like buttons**, light themes less white, dark controls a step lighter; one scale for text and corners; one focus ring; text readable at 4.5:1 in every theme.
- **Rows with their action**: the merge box and Finish review list each reason with what fixes it.
- **LGTM's own dropdowns, tooltips and icons** throughout, and PRs that slide to their new place on refresh.
- **Failures said one way**, with the GitHub limit and when it resets when that's the cause.
- **Needs Safari 17.4 or later**: an older web engine gets a message, not a half-styled app.
