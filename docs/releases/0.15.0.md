**Agent review sessions you can open, failures lgtm sorts out itself, merge blockers named, and a quieter page.**

**Agent reviews**
- **Open a review's session** (Settings → Coding agents → Keep agent review sessions, off): the review keeps its session, and its pill's menu (**W** on the PR) opens it where it ran, in a copy of the repo as it reviewed it. A Claude Code review opens in the Claude app; a Codex one in Terminal. See what it read and thought, or ask it why.

**Sorted out without you**
- **Update branch, Revert and committing suggestions** after a push you hadn't loaded go again on the branch's head now, instead of failing ("head sha didn't match"). Suggestions only when the push left their files alone.
- **A reply while your review is in progress** goes into that review (GitHub allows nothing else), and lgtm says so: Finish review sends it.
- **A moment's GitHub trouble** (a 502, 503, 504 or a query that timed out) is asked once more before it's an error. Only for reading.

**Clearer when it can't**
- **Why it can't merge**: when GitHub only says it's blocked, lgtm reads the branch's rules and names what's owed: unresolved conversations, a code owner's approval, more approvals, the merge queue, signed commits, a deployment. In Approve and merge's result and in the merge box.
- **A merge or review stopped by new commits** says so plainly, with **See what changed** (just the new commits) and **Reload**.

**A quieter page**
- **Finish review at the end of the page** sits in line with the files, as a comment box does, its button on the right.
- **Its note says only what isn't obvious**: the line comments going with it, merging after, Slack, files marked viewed, the next PR opening. Nothing for a plain comment.
- **Hidden files in one row**: "73 files hidden: 1 generated · 70 with no content change · 2 with only import changes · Show all".
- **Less text saying the obvious**: no "None." under a section showing 0, a shorter empty bell and recent list.
