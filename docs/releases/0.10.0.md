**Coding agents: Claude Code and Codex review with you.**

**Coding agents**
- Claude Code and Codex, each found through its CLI (signed in as you are) and switched on or off in Settings → Coding agents, with its own model and effort. Codex's models come from its own list. They run with no tools: they read what lgtm gives them and answer.
- A PR's **Agents** menu (<kbd>a</kbd>) runs any of them on it, picked each time; with one agent on, the button is that agent.
- New in onboarding: which agents are installed, and each one's lgtm-review skill.

**Reviews**
- An agent reviews each PR before it reaches "Needs your review" (Settings → Reviewing: off to start with, the agent, and a daily limit), or the PR in front of you from the Agents menu. PRs being reviewed wait under **Agents reviewing**.
- Findings go on the PR under your name, each starting with 🤖: in your pending review, or posted at once. A finding with a small, certain fix carries it as a suggested change the author applies in one click.
- Asked to review again, the agent reads only what changed since its last review; new pushes alone don't run it again.
- Its prompts are yours to word (Settings → Coding agents → Prompts).

**While you review**
- **Ask** about the PR, or select code to ask about just that, with follow-up questions. Conversations are kept: closing the panel loses nothing, and the Agents menu reopens any of this commit's.
- An answer becomes a comment on the code you asked about, or a paragraph of your review's summary, marked 🤖 and yours to edit first.
- **Fix** in a line comment's box: the agent rewrites the lines as your comment asks, as a suggested change.
- **Why did it fail?** on a failed check: the cause (quoting the log), whether the PR caused it, and the fix; ask it more from there.

**Coming back to a PR**
- **Did they address my comments?** When a PR you reviewed comes back with new commits, the agent marks each of your open threads addressed (with Resolve, or all at once) or not yet, and why. On your own PRs, the same for whoever asked for changes, before you ask them to look again.
- A desktop notification when an agent finishes while lgtm is in the background (Settings → Desktop notifications).

**Sessions**
- The Agents menu opens the PR's Claude Code session or Codex conversation, or starts one with the PR in the prompt.
- Codex gets the lgtm-review skill (install it from Settings) and an `lgtm-links` plugin: your reviews reach the conversation on your next message, and `/lgtm` opens a PR here.
  `codex plugin marketplace add bukuwarung/lgtm && codex plugin add lgtm-links@lgtm`

**Also**
- On GitLab, a suggestion on a range of lines covers every line of it.
- The review-in-progress banner names GitLab on a merge request.
