**Agent reviews that read the repo's own rules, and fixes for the reviewer list, mentions and the index.**

**Agent reviews**
- **They read the repo itself.** With a checkout of the repo on your Mac, the agent reviews in a read-only copy of the PR's base commit, made from your checkout (your branch and files untouched, the copy removed after). It reads the repo's CLAUDE.md or AGENTS.md, its skills and the docs they link to, as it would in a terminal.
- **Found where you work.** lgtm finds the checkout from where your Claude Code and Codex sessions worked, or the folder Settings names for the repo.
- **Kept to the copy.** Claude Code runs restricted to it, reading only. Codex reads through its shell under a permission profile that can't open your home folder, write, or reach the network.
- **What it read** shows in the agent pill's details: the repo files and skills it opened.
- Without a checkout, the repo's guides go into its prompt as before, now with the Markdown files they link to (coding-guidelines.md, say) and more room for them.

**Fixes**
- Someone you ask to review shows among the reviewers at once, not after a reload.
- A PR in the list only because it mentions you comes back for a new mention of you, not for any reply, and stays dismissed until then.
- Clicking a thread in the index no longer scrolls the index away from where you were.
